Patchbay Voice is a voice interface to pi, a multi-model AI coding agent. Hold a button, describe what you want built, and release. By the time you lower your phone, pi is already working.

The app talks to a lightweight server you run on your own Mac, alongside pi. Your audio is transcribed locally with faster-whisper, so it never leaves your machine, and the reply is read back to you. It is built for the moments you are not looking at a screen: reviewing what your agent just built while on a walk, then dictating the next instruction, keeping the whole exchange conversational.

What it does

- Hold to talk, or switch to the keyboard when you need precise input.
- Spoken replies with an adjustable speaking rate, so you can listen instead of read.
- One session per repository. Selecting a repo sets the agent's working directory and keeps each project's context separate.
- A model picker, so you can trade speed for capability from one turn to the next.
- Optional auto-commit and auto-push of saved notes, enabled only when the project is a Git repository (and, for push, has a remote), so a toggle is never a silent no-op.
- Designed so a turn always comes back with something audible. If transcription or the agent fails, you hear a short spoken notice instead of silence.

Patchbay Voice is a developer tool. It requires your own Mac running the open-source Patchbay Voice server (MIT licensed) with pi installed. It is not a standalone assistant and does not work on its own.

Source and setup: github.com/synodic-studio/patchbay-voice
