Patchbay Voice lets you talk to your codebase. Hold a button and ask about a project out loud, like what it does, how a piece works, or what changed in the last commit, and hear the answer back. When something is worth keeping, ask the agent to save a note or a plan, and it writes it to a folder in the repo for you.

It drives pi, a multi-model AI coding agent, with its tools deliberately scoped. The agent can read your files, search the code, and inspect git history, and it can save notes only to a path you choose. It reads and reasons about your project and records your thoughts. It does not modify your code.

It is built for the moments you are not looking at a screen: walking through what a codebase does, catching up on what changed, or dictating a plan for later, all conversational.

What it does

- Ask about your code by voice, or type when you need precision.
- Spoken replies, from the server or your device's own voice, at an adjustable rate.
- One session per repository, so each project's context stays separate.
- The agent reads files, searches, and inspects git history: log, diff, blame, branches.
- Save notes, plans, and summaries to a folder in the repo. The agent cannot touch anything outside it.
- Optionally commit and push those notes when the repository supports it.
- Designed so a turn always comes back with something audible, even if a step fails.

Patchbay Voice is a developer tool. It talks to a small open-source server (MIT licensed) that you run yourself, on macOS or Linux or a remote machine, with pi installed. It is not a standalone assistant.

Source and setup: github.com/synodic-studio/patchbay-voice
